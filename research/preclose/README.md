# Минутный бэктест TMOS / TMON перед закрытием

Исследование этапа B плана разработки. Функция сигнала импортируется из
`src/rotation_bot/strategy.py`; цена берётся до закрытия, не из финальной
дневной свечи.

Период: **12.07.2023–05.11.2026**. Раньше не было самого TMON.
Стартовый капитал 0 ₽, взносы 20 000 ₽ ежемесячно, всего 820 000 ₽.
Комиссии, обслуживание и проскальзывание отключены. Используется предположение
об освобождении сделок на ИИС типа Б; возврата НДФЛ со взносов нет.

Основной сценарий сохраняет лимит свежести 45 секунд из скелета. Отдельно
показаны последняя цена возрастом до 10 минут, проверка перед аукционом и
чувствительность к ограничению объёма. Эти варианты меняют разные условия;
они не объявлены одной и той же стратегией.

Лимит свежести на минутной истории проверяется по концу свечи. Реальный
момент последнего тика внутри минуты неизвестен, поэтому это приближение.
Уверенно выявляются 686 снимков возрастом более 45 секунд; точную свежесть
остальных без тиковых данных подтвердить нельзя.

## Воспроизведение

Из корня репозитория бота:

```sh
python research/preclose/fetch.py --workers 4
python research/preclose/run_backtest.py
python -m unittest discover -s research/preclose -p 'test_*.py' -v
```

Первой команде нужна сеть, токен брокера не требуется. Котировки загружаются
из публичного MOEX ISS. Raw JSON сохраняются с gzip-сжатием в `data/raw/`,
CSV — по месяцам в `data/minutes/`. Повторные запросы используют кеш.
`data/manifest.json` содержит точные URL и SHA-256.

Вычисление по сохранённым данным работает стандартным Python 3.11+.
Для графиков нужен matplotlib:

```sh
python research/preclose/plot.py
```

В исходной рабочей папке можно использовать уже подготовленное окружение:

```sh
../tmos_backtest/.venv/bin/python research/preclose/plot.py
```

Папка `data/` исключена из Git; отчёты и журналы лежат в `results/`.
Локальные токены и ИИС не используются и не изменяются.

## Важный результат проверки времени

До 23.03.2026 основная сессия заканчивалась в 18:50, а T−5 приходилось
на 18:45 — уже внутри аукциона закрытия. В минутной истории IMOEX в это
время часто есть только последнее значение около 18:40. Фильтр 45 секунд
пропускает такой снимок. После изменения расписания T−5 сдвигается на 18:55.

Кроме того, текущий скелет блокирует исполнение на аукционе. Этот тест
исследует будущую реализацию последовательных заявок по наблюдаемым
биржевым принтам, включая перенос незавершённых операций на следующий день.
Он не подтверждает, что текущий read-only скелет уже выполняет такие сделки.

В основном сценарии нельзя исполнять за минуту больше паёв, чем за неё
действительно торговалось. Однако весь объём по OPEN минуты — всё ещё
оптимистичный ценовой прокси: очередь, спред и встречные заявки неизвестны.
Результаты и различия всех допущений описаны в полном отчёте.
