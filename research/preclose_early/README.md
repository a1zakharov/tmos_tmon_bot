# TMOS / LQDT: внутридневная проверка до появления TMON

Отдельный эксперимент за 26.08.2020–11.07.2023. Старт 0 ₽, ежемесячно 20 000 ₽,
внешние расходы 0, ИИС типа Б без возврата со взносов. На дату конца расчёта
ИИС не закрывается: предполагается сохранение счёта до выполнения трёхлетнего срока.

Защитный актив — VTBM до 21.07.2022, затем LQDT, один ISIN RU000A1014L8.
Сырые котировки сохранены под фактическими тикерами; переименование не создаёт сделку.

```sh
python research/preclose_early/fetch.py --workers 4
python research/preclose_early/run.py
python -m unittest discover -s research/preclose -p 'test_*.py'
python -m unittest discover -s research/preclose_early -p 'test_*.py'
```

Для `plot.py` нужен Python с matplotlib. Расчёт и загрузка используют стандартную библиотеку.
`data/` игнорируется Git; ответы ISS кэшируются и повторная загрузка возобновляется.

Общий движок находится в `../preclose/run_backtest.py`. Его внутреннее имя защитной
роли `TMON` сопоставляется истории VTBM/LQDT. В экспортированных CSV используются
название `LQDT` и фактический `source_ticker`. Цены TMON в этом опыте не используются.

Сигнал: цена IMOEX ниже вчерашнего low → защитный фонд; выше high → TMOS; внутри →
сохранить цель. Время — 18:45 МСК, альтернативная диагностика — 18:35.
Это конец основной сессии с послеторговым периодом, как в предыдущем опыте.
Торговый период фондов завершался в 18:44:59; исполнение может переходить
на вечерние торги или следующий день. Проверка в 18:40 была бы отдельным правилом.
30.03.2022 учтён сокращённый день: 13:45 / 13:35 соответственно.
Варианты свежести 45 секунд и 10 минут считаются отдельно. Последняя полностью
законченная минута не доказывает точный возраст последнего тика; финальная дневная
свеча не подставляется в предварительный сигнал.

Исполнение: сначала продажа, затем покупка, минимум 1 секунда между операциями,
целые паи, лимит фактического минутного объёма. OPEN следующей допустимой минуты —
оптимистичная модель цены, не гарантия исполнения у брокера или на аукционе.
Во время биржевой паузы искусственных сделок нет; без свежего индекса цель сохраняется.
